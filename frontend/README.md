# SchoolConnect : frontend statique

Ouvrir `index.html` (ou copier le dossier dans `htdocs/schoolconnect/` avec XAMPP).
Pour tester les espaces : depuis `auth/connexion.html`, ouvrez directement `admin/`, `direction/`, `enseignants/` ou `parents/` (tableau-de-bord.html).

assets/css : base.css, connexion.css, layout.css | assets/js : app.js
auth/ | admin/ | direction/ | enseignants/ | parents/

Les données sont fictives. Les pages deviendront des `.php` avec le backend ;
toute vérification (session, rôle, relation parent-enfant, validation des notes) se fera côté serveur.
